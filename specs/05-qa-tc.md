### TC-001 신규 설치와 앱·CLI 기능 확인

- **목적**: 신규 설치와 앱·CLI 기능 확인 검증.
- **사전 조건**: 격리된 신규 시험 루트, 지원 후보 Codex 앱·CLI, 인증된 시험 계정. 전역 설정과 기존 codex 명령 사본·해시 확보. 실제 시험 대상은 Windows 터미널의 Codex CLI와 현재 GPT PC 앱의 Codex 작업 환경 각각이다.
- **절차**:
  1. GitHub 배포본의 시험 버전을 신규 루트에 설치한다.
  2. 앱·CLI별 버전과 선택 메뉴·훅 실제 동작 확인을 실행한다.
  3. system/과 projects/ 및 전역 설정·기존 명령의 변경 여부를 확인한다.
- **기대 결과**: 두 경로가 분리되고 앱·CLI의 지원/미지원/미확인이 구분된다. 실제 동작 미확인은 통과가 아니다. 전역 설정·기존 명령은 변경되지 않는다.
- **관련**: REQ-001, POL-002, POL-003, POL-009, SCR-001
- **실행 결과**: 보류 — 2026-11-20 첫 기술 실증의 부분 증거. CLI 0.170.0 stdio 연결·현재 PC 대화 읽기 확인. 실제 두 호스트의 선택/훅/지원 조합 전체 확인은 대기. 근거: qa/phase-0-results.md, qa/phase-0-local-checks.json, qa/host-probe.json. 제품 TC 전체 통과가 아님.
