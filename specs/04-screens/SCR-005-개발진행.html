Codex 앱 대화 표현 예시

1

현재 단계

예시: 개발·검증 반복 · 스펙 v1.0 · 상태는 실제 통과 결과가 아닙니다.

2

현재 작업

예시 요구 ID → 변경 파일 → 인수 조건 → 실행 검증을 연결해 표시합니다.

3

검증 결과

통과 1 / 실패 1 / 미실행 1 / 차단 0 (모두 목업 데이터) · 검증 대상 코드 버전 표시 현재 스펙·코드·환경 버전과 해당 검증의 실제 통과를 연결합니다. 오류 키·복구 주기를 보존합니다.

4

진행 제어

스펙 내부 실패는 자동 복구합니다. 범위·주요 설계·완료 기준 변경은 사용자 판단을 요청합니다. 명시적 중단을 존중합니다. 실행·배포 준비 중 계정·권한·비용 판단이 필요하면 대상·범위·필요 조치만 요청하고 대기합니다.

5
