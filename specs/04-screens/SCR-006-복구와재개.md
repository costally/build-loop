## 1. 화면 목적

- 실패 원인·보존 상태·복구 횟수·필요 조치를 확인한다.
- Codex 앱·CLI 대화의 개념 목업이다. 별도 웹 UI 구현이나 호스트 내부 UI 변경을 확정하지 않는다.

## 2. 레이아웃 (텍스트 와이어프레임)

```text
+--------------------------------------------------------------+
| [1] 복구 대상
| [2] 시도 이력
| [3] 다음 허용 작업
| [4] 중단·차단 경계
| [5] 다음 작업
+--------------------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ConversationView>
  <Section1 /> {/* [1] 복구 대상; POL-003, POL-004, POL-005, POL-006 */}
  <Section2 /> {/* [2] 시도 이력; POL-003, POL-004, POL-005, POL-006 */}
  <Section3 /> {/* [3] 다음 허용 작업; POL-003, POL-004, POL-005, POL-006 */}
  <Section4 /> {/* [4] 중단·차단 경계; POL-003, POL-004, POL-005, POL-006 */}
  <Section5 /> {/* [5] 다음 작업; POL-003, POL-004, POL-005, POL-006 */}
</ConversationView>
```

트리는 정보·동작 구분용이다. 실제 Codex 호스트 컴포넌트를 교체하는 구현 요구가 아니다.

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 복구 대상 | 정보 | 예시: 선택 메뉴 사용 불가 · 미응답 질문과 기존 답변 보존 | POL-003, POL-004, POL-005, POL-006 |
| 2 | 시도 이력 | 정보 | 최초 실패 후 복구 1/3회 예시 · 원인 / 변경 / 검증 결과 표시 오류 키는 프로젝트·작업·검사·실패 분류·환경으로 구분합니다. 실행 직전 시도와 결과 미확인도 보존합니다. | POL-003, POL-004, POL-005, POL-006 |
| 3 | 다음 허용 작업 | 정보 | 지원 버전·모드·설정을 확인합니다. 복구되면 같은 미응답 질문으로 돌아갑니다. | POL-003, POL-004, POL-005, POL-006 |
| 4 | 중단·차단 경계 | 정보 | 3회 실패 시 상태를 보존하고 필요한 조치만 보고합니다. 인증·권한·사용자 답변 대기는 즉시 대기합니다. 배포 계정·권한·비용 판단이 필요할 때도 응답을 추정하지 않고 필요한 조치를 표시합니다. | POL-003, POL-004, POL-005, POL-006 |
| 5 | 다음 작업 | 동작 | 복구 성공 예시 → 같은 인터뷰 질문 재개 | POL-003, POL-004, POL-005, POL-006 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 단계별 자료 준비됨 | 구성 요소 1~5 표시. 예시 데이터임을 표시 |
| 로딩 | 조회·저장·검사 중 | 보존된 질문과 복구 조건을 확인하고 있습니다. |
| 빈 상태 | 표시할 자료 없음 | 아직 기록된 복구 시도가 없습니다. |
| 에러 | 정책 위반 또는 실패 | 같은 오류의 자동 복구를 3회 시도했지만 해결되지 않았습니다. 진행 상태를 보존했습니다. 필요한 조치: {조치} |

목업 상단의 상태 선택은 검토 도구이며 제품 기능이 아니다. 비기본 상태에서는 주요 동작을 비활성화한다.

## 7. 인터랙션 상세

- 횟수는 재시작만으로 초기화하지 않는다. 성공하면 발생 위치(인터뷰·개발·검토)로 돌아간다. 이 목업은 메뉴 복구 사례를 표현하며 실제 복구하지 않는다.
- 상단 앱/CLI 선택은 표현 예시만 바꾸며 기능 지원 통과를 의미하지 않는다.
- 비기본 상태에서는 주요 동작을 비활성화한다. 오류 복구는 POL-006을 따른다.
- 목업 내 클릭은 실제 파일·승인·프로젝트 상태를 변경하지 않는다.
