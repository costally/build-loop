## 1. 화면 목적

- 문서·목업·인수 조건과 미정 항목을 검토하고 승인 범위를 구분한다.
- Codex 앱·CLI 대화의 개념 목업이다. 별도 웹 UI 구현이나 호스트 내부 UI 변경을 확정하지 않는다.

## 2. 레이아웃 (텍스트 와이어프레임)

```text
+--------------------------------------------------------------+
| [1] 검토 대상
| [2] 스펙 요약
| [3] 미정과 누락
| [4] 승인 구분
| [5] 다음 작업
+--------------------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ConversationView>
  <Section1 /> {/* [1] 검토 대상; POL-001, POL-005, POL-008 */}
  <Section2 /> {/* [2] 스펙 요약; POL-001, POL-005, POL-008 */}
  <Section3 /> {/* [3] 미정과 누락; POL-001, POL-005, POL-008 */}
  <Section4 /> {/* [4] 승인 구분; POL-001, POL-005, POL-008 */}
  <Section5 /> {/* [5] 다음 작업; POL-001, POL-005, POL-008 */}
</ConversationView>
```

트리는 정보·동작 구분용이다. 실제 Codex 호스트 컴포넌트를 교체하는 구현 요구가 아니다.

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 검토 대상 | 정보 | 예시 스펙 세트 v1.0 · 브리프 / PRD / 정책 / IA·화면 / QA TC 실제 화면과 별개로 비화면 입력·출력·실행·오류 명세 및 IA 연결을 검토합니다. | POL-001, POL-005, POL-008 |
| 2 | 스펙 요약 | 정보 | 핵심 기능·제외 범위·실제 시연 환경·합격 조건을 확인합니다. 상세는 담당 문서 ID로 연결합니다. | POL-001, POL-005, POL-008 |
| 3 | 미정과 누락 | 정보 | 예시: 필수 미정 1건. 내용 확인 전 구현으로 넘어가지 않습니다. | POL-001, POL-005, POL-008 |
| 4 | 승인 구분 | 정보 | PRD 승인과 스펙 세트 승인은 다릅니다. 대상 문서·버전을 명시하고 사용자 답을 기다립니다. 승인 대상 manifest·버전·검증된 사용자 응답 출처를 연결하며 임의 user 표기로 승인하지 않습니다. | POL-001, POL-005, POL-008 |
| 5 | 다음 작업 | 동작 | 필수 미정 해결 후 스펙 세트 승인 예시 → 개발 진행 | POL-001, POL-005, POL-008 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 단계별 자료 준비됨 | 구성 요소 1~5 표시. 예시 데이터임을 표시 |
| 로딩 | 조회·저장·검사 중 | 문서 버전과 참조·필수 미정을 확인하고 있습니다. |
| 빈 상태 | 표시할 자료 없음 | 아직 검토할 스펙 세트가 없습니다. |
| 에러 | 정책 위반 또는 실패 | 현재 단계의 완료 조건이 충족되지 않았습니다. 다음 작업: {작업} |

목업 상단의 상태 선택은 검토 도구이며 제품 기능이 아니다. 비기본 상태에서는 주요 동작을 비활성화한다.

## 6. 입력 유효성 (입력 폼이 있는 경우)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 승인 응답 | Y | 대상·버전과 명시적 사용자 의사 확인 | 이 단계의 사용자 승인이 없습니다. 승인 대상과 버전을 확인해 주세요. | POL-001 |

## 7. 인터랙션 상세

- 필수 미정·깨진 참조가 있으면 승인 전 보완한다. HTML 버튼은 미정 해결 및 승인 완료라는 별도 예시 상태로 이동할 뿐 현재 스펙을 승인하지 않는다. 변경 요청은 POL-008을 적용한다.
- 상단 앱/CLI 선택은 표현 예시만 바꾸며 기능 지원 통과를 의미하지 않는다.
- 비기본 상태에서는 주요 동작을 비활성화한다. 오류 복구는 POL-006을 따른다.
- 목업 내 클릭은 실제 파일·승인·프로젝트 상태를 변경하지 않는다.
