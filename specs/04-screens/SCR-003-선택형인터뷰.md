## 1. 화면 목적

- 한 질문에 대안·추천 이유를 보고 답을 확정한다.
- Codex 앱·CLI 대화의 개념 목업이다. 별도 웹 UI 구현이나 호스트 내부 UI 변경을 확정하지 않는다.

## 2. 레이아웃 (텍스트 와이어프레임)

```text
+--------------------------------------------------------------+
| [1] 확정 결정과 질문
| [2] 선택 메뉴
| [3] 추천 이유
| [4] 답변 처리
| [5] 다음 작업
+--------------------------------------------------------------+
```

## 3. 컴포넌트 트리 (개발 인수인계용)

```jsx
<ConversationView>
  <Section1 /> {/* [1] 확정 결정과 질문; POL-003, POL-004, POL-006 */}
  <Section2 /> {/* [2] 선택 메뉴; POL-003, POL-004, POL-006 */}
  <Section3 /> {/* [3] 추천 이유; POL-003, POL-004, POL-006 */}
  <Section4 /> {/* [4] 답변 처리; POL-003, POL-004, POL-006 */}
  <Section5 /> {/* [5] 다음 작업; POL-003, POL-004, POL-006 */}
</ConversationView>
```

트리는 정보·동작 구분용이다. 실제 Codex 호스트 컴포넌트를 교체하는 구현 요구가 아니다.

## 4. 구성 요소 정의

| # | 요소 | 유형 | 내용/동작 | 관련 정책 |
|---|---|---|---|---|
| 1 | 확정 결정과 질문 | 정보 | 예시 질문: 이 프로젝트의 1차 완료는 어떻게 확인할까요? · 실제 프로젝트의 답변이 아닌 목업 데이터 | POL-003, POL-004, POL-006 |
| 2 | 선택 메뉴 | 정보 | 합의한 핵심 흐름의 실제 시연 후 사용자 승인 (추천) / 로컬 실행 확인 / 배포 환경 사용 확인 | POL-003, POL-004, POL-006 |
| 3 | 추천 이유 | 정보 | 결과물을 직접 써 보고 완료를 판단할 수 있습니다. 다른 안은 확인할 환경과 범위가 달라집니다. | POL-003, POL-004, POL-006 |
| 4 | 답변 처리 | 정보 | 아직 확정하지 않았습니다. 선택지를 고르거나 자유 의견을 적은 뒤 확정합니다. 취소·빈 답은 확정하지 않습니다. 결과물 유형·실행/시연 환경·배포 필요 여부·핵심 확인 흐름을 한 결정씩 확인합니다. | POL-003, POL-004, POL-006 |
| 5 | 다음 작업 | 동작 | 답변 확정 예시 · 다음 예시는 인터뷰 종료 후 스펙 검토입니다. | POL-003, POL-004, POL-006 |

## 5. 상태별 화면

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 단계별 자료 준비됨 | 구성 요소 1~5 표시. 예시 데이터임을 표시 |
| 로딩 | 조회·저장·검사 중 | 확정 답을 저장하고 다음 질문을 준비하고 있습니다. |
| 빈 상태 | 표시할 자료 없음 | 선택하거나 의견을 입력해 주세요. 아직 답변은 확정되지 않았습니다. |
| 에러 | 정책 위반 또는 실패 | 선택 메뉴를 사용할 수 없습니다. 답변을 보존하고 복구 후 같은 질문에서 이어갑니다. |

목업 상단의 상태 선택은 검토 도구이며 제품 기능이 아니다. 비기본 상태에서는 주요 동작을 비활성화한다.

## 6. 입력 유효성 (입력 폼이 있는 경우)

| 필드 | 필수 | 형식/제한 | 실패 시 문구 | 관련 정책 |
|---|---|---|---|---|
| 선택 또는 자유 의견 | Y | 사용자 응답·비어 있지 않은 답, 취소 아님 | 선택하거나 의견을 입력해 주세요. 아직 답변은 확정되지 않았습니다. | POL-003 |

## 7. 인터랙션 상세

- 확정 후 실제 흐름에서는 남은 질문을 이어간다. 결과물 유형·실행/시연 환경·배포 필요 여부·핵심 확인 흐름을 한 결정씩 확인한다. 질문 ID와 결정 기록을 저장하고 중복 질문하지 않는다. 메뉴 장애는 SCR-006으로 이동하며 텍스트 전용으로 전환하지 않는다. 이 HTML 라디오는 흐름 검토용이며 Codex 네이티브 도구 지원 증거가 아니다.
- 상단 앱/CLI 선택은 표현 예시만 바꾸며 기능 지원 통과를 의미하지 않는다.
- 비기본 상태에서는 주요 동작을 비활성화한다. 오류 복구는 POL-006을 따른다.
- 목업 내 클릭은 실제 파일·승인·프로젝트 상태를 변경하지 않는다.
